# راهنمای جامع IDM (نسخه ۲.۰ - بازطراحی شده برای کافه بازار)

این پروژه بازطراحی کامل و مدرن‌سازی اپلیکیشن راهنمای اینترنت دانلود منیجر (IDM) بر پایه جدیدترین استاندارد‌های اندروید، طراحی متریال ۳ و سیستم تبلیغاتی بازار است.

---

## 🌟 ویژگی‌ها و تغییرات کلیدی در نسخه ۲.۰

### ۱. معماری و استانداردهای فنی جدید
- **زبان برنامه نویسی:** مهاجرت کامل به **Kotlin**
- **نسخه اندروید هدف:** **Target SDK 35 (Android 15)** با حداقل نسخه **Min SDK 24 (Android 7.0)**
- **مبتنی بر کامپوننت‌های مدرن:** `MaterialCardView`, `MaterialToolbar`, `RecyclerView`, `ViewBinding`, `PreferencesManager`
- **مدیریت تصاویر:** استفاده از کتابخانه قدرتمند `Glide` جهت بارگذاری بهینه عکس‌ها بدون اشغال حافظه

### ۲. رابط کاربری مدرن (Material Design 3)
- پشتیبانی کامل از **حالت شب (Dark Mode)** و هماهنگی خودکار با سیستم‌عامل
- **RTL کامل** و تایپوگرافی مناسب متون فارسی
- **جستجوی آنی و لحظه‌ای:** جستجوی هوشمند بین عناوین و کل متن‌های آموزشی
- **بخش نشان‌شده‌ها (Bookmarks):** امکان ذخیره مباحث مهم برای دسترسی سریع
- **تنظیم اندازه قلم:** تغییر سایز متن به دلخواه کاربر از بخش تنظیمات
- **قابلیت کپی و اشتراک‌گذاری:** دکمه‌های مستقیم کپی و ارسال متن به سایر برنامه‌ها

### ۳. سیستم درآمدزایی و تبلیغات (ویژه کافه بازار)
- یکپارچه‌سازی شده با **تپسل پلاس (Tapsell Plus SDK)**:
  - **تبلیغات بنری استاندارد (Standard Banner):** در پایین صفحه‌ی اصلی و صفحه آموزش‌ها
  - **تبلیغات بین‌برنامه‌ای (Interstitial):** هنگام ورود به فصل‌ها و آموزش‌ها با مدیریت هوشمند
- فایل تنظیمات تبلیغات در مسیر `ir.persianweb.idmguide.ads.AdManager` قرار دارد و به‌راحتی با جایگزینی `Zone ID` و `App Key` فعال می‌شود.

---

## 🛠 نحوه باز کردن و بیلد در Android Studio

1. نرم‌افزار **Android Studio** (نسخه Hedgehog یا بالاتر) را باز کنید.
2. گزینه **Open** را انتخاب کرده و پوشه فعلی (`idm`) را انتخاب نمایید.
3. اجازه دهید فرایند `Gradle Sync` کامل شود.
4. پروژه آماده اجرا و خروجی APK / AAB برای انتشار در کافه بازار است.

---

## 🔑 تنظیم کلیدهای تبلیغات تپسل
برای فعال‌سازی آگهی‌های اختصاصی خود در کافه بازار، فایل زیر را باز کنید:
`app/src/main/java/ir/persianweb/idmguide/ads/AdManager.kt`

و مقادیر زیر را با کلیدهای دریافتی از پنل تپسل جایگزین نمایید:
```kotlin
const val TAPSELL_KEY = "کلید_اپلیکیشن_شما_در_تپسل"
const val ZONE_ID_BANNER = "شناسه_تبلیغ_بنری_شما"
const val ZONE_ID_INTERSTITIAL = "شناسه_تبلیغ_بین_برنامه‌ای_شما"
```
